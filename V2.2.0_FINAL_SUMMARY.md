## 🗄️ Database Schema

### New Tables (3)

1. **login_attempts** - Rate limiting tracking
   - Columns: id, username, success, ip_address, user_agent, attempted_at
   - Indexes: username, attempted_at

2. **password_reset_tokens** - Password reset management
   - Columns: id, token, user_id, created_at, expires_at, used_at, created_by
   - Indexes: token, user_id, expires_at

3. **audit_log** - Security event logging
   - Columns: id, event_type, user_id, username, ip_address, user_agent, event_data, created_at
   - Indexes: event_type, user_id, created_at, username

### Updated Tables

**users** table - 9 new columns:
- `account_locked` - Account lockout flag
- `locked_until` - Lockout expiration timestamp
- `failed_login_attempts` - Failed attempt counter
- `last_failed_login` - Last failed attempt timestamp
- `password_changed_at` - Password change tracking
- `force_password_change` - Force change on next login
- `article_quota` - Article creation limit
- `scraper_quota` - Scraper profile limit
- `quota_reset_at` - Quota reset timestamp
